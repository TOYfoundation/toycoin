# ToyScan

Explorer für ToyChain mit **Warnampel** (grün/gelb/rot) für Obergrenze, Fair Launch, Emission, Epochen, Verfassung, Konsens, Startphase und Schutzregeln. Zeigt für jede Adresse auch die Guthaben auf anderen EVM-Ketten. ToyScan hat nie Schlüssel.

**Status:** Konzept, noch kein Code. Bau in Meilenstein M11.

- Konzept: `../docs/05-toyscan.md`
- Der ToyChain-Knoten liefert die Daten über `toy_`-Methoden (M7).
