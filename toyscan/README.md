# ToyScan

Explorer für ToyChain mit Supply-Daten und **Ampel** (grün/gelb/rot) für die Regeln zu Obergrenze, Reserve, Bridge-Tresoren und Altbestand auf Polygon und Ethereum.

**Status:** Konzeptphase. Noch kein Code.

- Kriterien der Ampel: `../docs/04-toyscan-und-altbestand.md`
- Geplantes Detailkonzept: `../docs/08-toyscan.md` (Datenquellen, genaue Berechnung jeder Regel)
- Der ToyChain-Knoten stellt die nötigen Daten maschinenlesbar bereit (Gesamtmenge, gemintet, Reserve, Epoche, Emissionsfaktor).

Reihenfolge laut Plan: erst der ToyChain-Kern (Phase 1), dann ToyScan.
